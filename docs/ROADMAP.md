# ROADMAP

## 現在の最新ベース

- 最新バージョン：v0.7.2
- 方針：スマホ縦画面向けのミニ狩猟アクション
- 公開想定：GitHub Pages
- 技術構成：HTML / CSS / JavaScriptのみ。ビルド不要、外部ライブラリ不要。

## 次に入れると良いもの

### v0.8.0候補：武器種追加

- 武器選択画面
- 大剣：現行の重い3段コンボを継続
- 片手剣：軽い連続攻撃、短い硬直、初心者向け
- 双剣：高DPS、スタミナ消費多め、連打向け
- 武器ごとの攻撃力・リーチ・硬直・コンボ性能を `js/data/weapons.js` で調整可能にする

### v0.8.x候補：クエスト進行

  - 特定モンスター討伐数

- 難度表示の強化

### v0.9.0候補：モンスター追加

- 飛行系
- 炎系

## 注意

既存のセーブキーは `beast_hunt_mini_save_v2` です。装備・素材・討伐数を扱う更新では、既存セーブをなるべく壊さないようにしてください。

v0.7.2時点では `BH.SAVE_VERSION = 4` を維持しています。表示・HUD・文書だけの変更では保存スキーマを変えない方針です。
