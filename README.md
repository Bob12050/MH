## 操作

### スマホ

- 左下スティック：移動
- タップ：攻撃（連打で3段コンボ）
- フリック：回避（滑らせた方向へ。敵攻撃に合わせるとジャスト回避）
- 長押し：回復薬使用
- ロックオン：常時オート
- 右上メニュー：一時停止 / クエスト選択へ戻る / リタイア

### PC

- WASD / 矢印：移動
- Space / J：攻撃
- Shift / L：回避
- E / I：回復
- Esc：一時停止

## GitHub Pagesへの配置

このフォルダの中身をリポジトリ直下に置いてください。

```text
index.html
css/
js/
assets/
docs/
README.md
```

その後、GitHub Pagesの公開元をリポジトリ直下にすれば動きます。
